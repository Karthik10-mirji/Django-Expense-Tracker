Django Expense Tracker
A web-based expense management application developed using Python and Django. It helps users manage daily expenses, organize transactions, and visualize spending through charts and reports.
Features

User Authentication: User registration and login.
Expense Management: Add, view, and manage daily expenses.
Expense Categories: Organize expenses for easier tracking.
Interactive Charts: Visualize spending patterns and financial information.
API Integration: API support for accessing application data.
Database Management: Store application data using SQLite.

Technologies Used

Python
Django
HTML5
CSS3
JavaScript
SQLite
REST API

Installation and Setup


Clone this repository:
git clone https://github.com/Karthik10-mirji/Django-Expense-Tracker.git



Navigate to the project folder:
cd Django-Expense-Tracker



Install Django:
python -m pip install django



Apply database migrations:
python manage.py migrate



Start the development server:
python manage.py runserver



Open your browser and visit:
http://127.0.0.1:8000/


Project Structure

ExpenseTracker/ — Django project configuration.
home/ — Application logic, models, views, and API-related code.
templates/ — HTML templates.
static/ — CSS, JavaScript, and images.
manage.py — Django management utility.
